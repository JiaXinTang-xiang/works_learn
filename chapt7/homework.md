## 作业 1：硬件回环自测

**接线**：USB-TTL 插电脑 → 用杜邦线把模块的 **TX 和 RX 两个引脚短接**（自发自收）。

**跑之前**：
1. `ls /dev/ttyUSB* /dev/ttyACM*` 找到你的串口；
2. 若是 `Permission denied`：`sudo usermod -a -G dialout $USER`，然后**注销重新登录**；
3. 把端口路径传进去（默认 `/dev/ttyUSB0`）：
   ```bash
   ./build/hw1_loopback /dev/ttyUSB0
   ```

**验收标准**：打印出 `===== 全校验通过，数据还原 =====`，且还原的 X/Y/Z/Yaw/置信度和原值完全一致。

## 作业 2：校验防护测试（故意篡改一个字节）

**目的**：证明 CRC8 真的能拦下"噪声翻转比特"。

**方式一（推荐）**：直接跑我写好的 `hw2_corrupt_test`（内部已在解包前执行 `rx_raw[5] ^= 0xFF`）：
```bash
./build/hw2_corrupt_test /dev/ttyUSB0
```

**方式二**：在 `hw1_loopback.cpp` 的**步骤 4（帧头检查）之前**加一行：
```cpp
rx_raw[5] ^= 0xFF;   // 故意翻转 Payload 里 x 的中间字节
```
重新编译运行，看它是否从"校验通过"变成"CRC8 校验失败，本帧被丢弃"。

**验收标准**：程序打印 `CRC8 校验失败` 并退出，而不是解包出一个错误坐标。
