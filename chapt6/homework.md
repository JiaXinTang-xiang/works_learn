## 作业 1：编译运行多线程示例

- **代码**：`hw1_multithread.cpp`（采图线程 + 算法线程），配套 `PingPongFrameBuffer.hpp`（零拷贝双缓冲）
- **构建**：`cmake -B build && cmake --build build -j && ./build/hw1_multithread`
- **实际输出**：

```
[采图线程] 启动成功，正在高速取流...
[算法主线程] 启动成功，按 ESC 退出。
[采图线程] 采集帧率: 60 FPS
[算法主线程] 处理帧率: 32 FPS
...
```

- **观察**：
  - 采图线程 60 FPS，算法线程（含 25ms 睡眠）只有 ~32 FPS，但挥手画面依然毫秒级响应、无拖影 —— 证明采图与计算彻底解耦了。
  - 帧率 60 vs 32 的差值，正是"硬件采图速度 > 算法速度"，靠丢弃历史帧 + 只取最新帧解决了积压。
